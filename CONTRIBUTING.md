# Guide de Contribution

Merci de votre intérêt pour contribuer à **ai-evaluation-pratique** !

## Comment Contribuer

### Signaler un Bug ou Proposer une Amélioration

1. Ouvrez une [issue](https://github.com/lafabriq/ai-evaluation-pratique/issues)
2. Décrivez clairement le problème ou la suggestion
3. Ajoutez des exemples concrets si possible

### Proposer du Nouveau Contenu

1. **Fork** ce repo
2. **Créez** une branche pour votre contribution
3. **Respectez** la structure et le format existants
4. **Soumettez** une Pull Request

## Standards de Qualité

### Ton et Style

- **Langage simple** : Pas de jargon technique non expliqué
- **Business-first** : Toujours partir du problème business
- **Actionnable** : Chaque contenu doit pouvoir être utilisé immédiatement
- **Exemples concrets** : Illustrer avec des cas réels

### Format des Fichiers

Chaque fichier Markdown doit inclure :
- Un titre clair
- Le problème ou l'objectif
- La solution proposée
- Un Quick Start ou résumé actionnable
- Des exemples concrets

### Checklist Avant Soumission

- [ ] Le contenu répond à un vrai problème manager
- [ ] Il est utilisable en moins de 15 minutes
- [ ] Les exemples sont concrets et chiffrés
- [ ] Les liens internes sont fonctionnels
- [ ] Le tone est business-friendly

## Types de Contributions Recherchées

- **Nouveaux exemples** : Cas d'évaluation documentés
- **Amélioration des templates** : Plus de templates pratiques
- **Traductions** : Versions en d'autres langues
- **Corrections** : Typos, liens cassés, clarifications

## Code de Conduite

- Soyez respectueux et constructif
- Focalisez sur la valeur pour les managers non-techniques
- Partagez vos expériences terrain

## Questions ?

Ouvrez une [issue](https://github.com/lafabriq/ai-evaluation-pratique/issues) ou contactez [LaFabriqAI](https://lafabriq.ai).
