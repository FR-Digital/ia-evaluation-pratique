# ai-evaluation-pratique

> **Savoir si votre IA fonctionne bien, sans être data scientist**

## Le Problème

- Votre équipe technique vous dit "92% de précision" mais vous ne savez pas si c'est bon ou mauvais
- Vous ne savez pas quelles questions poser pour évaluer la qualité de votre IA
- Vous n'avez pas de framework clair pour décider si un projet IA doit continuer ou s'arrêter

## La Solution

Ce repo vous donne les outils pour évaluer votre IA avec 3 questions simples, dans l'ordre :

1. **Est-ce que ça marche ?** (Tests techniques)
2. **Est-ce que c'est utilisé ?** (Adoption utilisateurs)
3. **Est-ce que ça rapporte ?** (Impact business)

## Exemple Concret

**Cas : Chatbot de Support Client**

| Niveau | Question | Résultat | Décision |
|--------|----------|----------|----------|
| 1 | Est-ce que ça marche ? | 78% de bonnes réponses sur 100 cas | ✅ Continuer |
| 2 | Est-ce que c'est utilisé ? | 65% d'adoption, 3.8/5 satisfaction | ✅ Continuer |
| 3 | Est-ce que ça rapporte ? | ROI = 71% (180k€ gains - 105k€ coûts) | ✅ Production |
